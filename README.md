🌿 AI Emotion Journal
A Mental-Wellbeing Tool by Mind-Haven

The AI Emotion Journal helps users express feelings and receive supportive emotional insights.
Using natural-language processing (NLP), it understands your mood and generates gentle reflections to improve emotional clarity and balance.

✨ Features

🧠 AI Mood Detection — Detects emotions like joy, stress, sadness, frustration, calmness.

💬 Empathetic Reflections — Generates supportive guidance based on user input.

📘 Daily Emotional Logs — Encourages consistent emotional journaling.

⚡ Lightweight & Fast — Simple but powerful model for wellbeing apps.

🛠️ Technologies Used

Python

HuggingFace Transformers

Sentiment & Emotion NLP Models

▶️ Example Code (How It Works)
from transformers import pipeline

emotion = pipeline("sentiment-analysis")
result = emotion("Today I felt overwhelmed but hopeful.")
print(result)
